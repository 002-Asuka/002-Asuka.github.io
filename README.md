## 评论

每篇文章底部使用 [giscus](https://giscus.app/zh-CN) 评论，数据保存在本仓库的 [Discussions](https://github.com/002-Asuka/002-Asuka.github.io/discussions)。新文章会自动带有评论区，不需要单独配置。

- 点击“使用 GitHub 登录”后发表评论。第一次使用需要在 GitHub 授权 giscus 代表自己发表评论。
- 登录后，点击评论旁的表情按钮，选择 👍 点赞；再次点击可取消。
- 删除评论：点击该评论的时间链接进入 GitHub，在评论右上角的 `…` 菜单选择 **Delete**。评论作者能删除自己的评论，仓库所有者能删除所有评论。
- 评论和点赞直接同步，无需提交文章或等待网站重新构建。

文章网址用于关联评论，发布后尽量不要改文章文件名，以免评论关联到不同网址。`comments.json` 保存仓库与分类 ID，`giscus.json` 限制评论区允许的站点，`public/styles/comments.css` 配合现有毛玻璃样式。
